# razi-school-v10 — موقع الثانوية التأهيلية الرازي (V10: إشعارات Push خارج المتصفح + تحسين الظهور في البحث)
الموقع العام + لوحة إدارة (/admin/) متصلة بـ Supabase: أخبار وإعلانات واستعمال الزمن والدروس والأساتذة والمعرض والأنشطة والأندية والإنجازات ومعلومات المؤسسة.

## التشغيل محليًا
`python -m http.server 8000` — بدون إعدادات تظهر حالات فارغة (لا بيانات تجريبية). للتجربة: `.env` فيه `RAZI_DEMO=1` ثم `node scripts/build-config.js`.

## الإعداد الكامل (بالترتيب)
1. `docs/ADMIN_SETUP.md` — Supabase، الترحيل 001 ثم 002، حساب المسؤول، متغيرات Vercel، الاختبارات.
2. `docs/CMS_TIMETABLE.md` — بنية استعمال الزمن وبقية الأقسام.
3. `docs/ARCHITECTURE.md` و`docs/DESIGN_SYSTEM.md` — المعمارية العامة ونظام التصميم (الموقع: أخضر/ذهبي، لوحة الإدارة: أزرق/أبيض).
4. `docs/AUDIT_V3.1.md` و`razi-v3-action-plan.md`/`razi-v3-negatives.md` (في مجلد outputs الأعلى) — سجلّ التدقيق والمخاطر السابقة.

## الاختبارات
`npm run test:all` (أو كل واحد على حدة): `test:build` · `test:design` (+`tests/contrast.py`) · `test:e2e` (الموقع العام) · `test:cms` (استعمال الزمن وبقية الأقسام) · `node tests/supabase.integration.mjs` (يتطلب مشروع Supabase اختباريًا حقيقيًا، غير مشمول في test:all).

## الترقيم
هذا المجلد هو **V10** (فوق V8 لا بديلًا عنه). التغييرات في `docs/V10_NOTES.md`. أي تطوير قادم يُسلَّم في مجلد جديد بالاسم نفسه مع ترقية الرقم (V7 ثم V8…)، فوق V6 لا بديلًا عنه.


## جديد في V8
- **هوية**: أزرق مؤسسي عميق وكهربائي + أصفر كريمي دافئ (الفاتح) + أسود عميق (الداكن). الألوان في أعلى `css/styles.css`، وتحقق التباين `python tests/contrast.py`.
- **Hero بلا صور**: `index.html` + `css/v8.css` + `js/hero.js`. كرات ضوئية وأقواس وحبيبات + شعار ثلاثي الأبعاد (SVG مُعاد تصميمه، طبقات CSS 3D تميل مع المؤشر والتمرير).
- **شريط الرازي الأزرق** (`js/hero.js`): Canvas 2D بإسقاط منظوري وتظليل انعكاسي؛ يتأثر بتقدّم التمرير داخل `.hero` فقط، وفي نهاية الـ Hero ينحني ويتقلّص ويهبط ويختفي كليًا. لا يتبع المستخدم لأي قسم/صفحة. تقليل الحركة = صورة ثابتة. على الهاتف تركيبة منفصلة (أنحف، تجزئة أقل)، وخفض تلقائي للدقة إن تأخر الرسم.
- **انتقال الوضع**: كشف دائري من زر التبديل عبر View Transitions (مع بديل fade وتقليل الحركة) — `js/ui.js`.
- **ثنائي اللغة كاملًا**: `data/i18n.js` (المفتاح = النص العربي، القيمة = الفرنسي) + `data-x` في HTML + `X()` في `app.js`. تبديل اللغة يعيد رسم كل الأقسام ويقلب الاتجاه. محتوى المؤسسة نفسه (أخبار، أسماء) يبقى بلغته كما أدخلته الإدارة.
- **دليل الرازي · RAZI AI**: زر عائم + نافذة + صفحة `assistant.html` (`js/assistant.js`). يجيب من المحتوى المنشور فقط ولا يخترع بيانات؛ واجهة `RAZI_AI.answer()` معزولة لاستبدالها لاحقًا بـ RAG.
- **معاينة بمحتوى تجريبي**: `npm run demo` (يعمل على كل الأنظمة) ثم `python -m http.server`. للعودة للإعداد الآمن: `npm run build`. بناء Vercel يمنع الوضع التجريبي.
- **الخطوط**: `npm run fonts` (يحتاج إنترنت) يضيف Fraunces للعناوين الفرنسية؛ قبله تُستعمل خطوط النظام.
- مخطّط الشريط (sketch) لم يُرفق مع الطلب؛ التنفيذ اتبع الوصف النصي (شريط عمودي على اليمين). عدّل `pose()` في `js/hero.js` لمطابقة الرسم.

## إشعارات الرازي + كشف التمرير (جديد)
جرس إشعارات لكل زائر (بلا حساب) وWeb Push اختياري، وإدارة من لوحة الإدارة، وكشف محتوى هادئ عند التمرير، وأُزيل مؤشر التمرير من الـ Hero. يتطلب ترحيل `003_notifications.sql` ومفاتيح VAPID — راجع `docs/NOTIFICATIONS.md`. اختبارات: `npm run test:push` و`npm run test:ui`.
