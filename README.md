# موقع الرازي — V6 (الحزمة الكاملة حتى الآن)
الموقع العام + لوحة إدارة (/admin/) متصلة بـ Supabase: أخبار وإعلانات واستعمال الزمن والدروس والأساتذة والمعرض والأنشطة والأندية والإنجازات ومعلومات المؤسسة.

## التشغيل محليًا
`python -m http.server 8000` — بدون إعدادات تظهر حالات فارغة (لا بيانات تجريبية). للتجربة: `.env` فيه `RAZI_DEMO=1` ثم `node scripts/build-config.js`.

## الإعداد الكامل (بالترتيب)
1. `docs/ADMIN_SETUP.md` — Supabase، الترحيل 001 ثم 002، حساب المسؤول، متغيرات Vercel، الاختبارات.
2. `docs/CMS_TIMETABLE.md` — بنية استعمال الزمن وبقية الأقسام.
3. `docs/ARCHITECTURE.md` و`docs/DESIGN_SYSTEM.md` — المعمارية العامة ونظام التصميم (الموقع: أخضر/ذهبي، لوحة الإدارة: أزرق/أبيض).
4. `docs/AUDIT_V3.1.md` و`razi-v3-action-plan.md`/`razi-v3-negatives.md` (في مجلد outputs الأعلى) — سجلّ التدقيق والمخاطر السابقة.

## الاختبارات
`npm run test:all` (أو كل واحد على حدة): `test:build` · `test:design` (+`tests/contrast.py`) · `test:e2e` (الموقع العام) · `test:cms` (استعمال الزمن وبقية الأقسام) · `node tests/supabase.integration.mjs` (يتطلب مشروع Supabase اختباريًا حقيقيًا، غير مشمول في test:all).
