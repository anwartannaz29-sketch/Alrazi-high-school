# لوحة الإدارة: استعمال الزمن وبقية الأقسام

## البنية
- `supabase/migrations/002_cms_timetable.sql` — إضافي فوق 001: `timetables → timetable_periods → timetable_entries`، وجداول `teachers / resources / gallery_items / clubs / achievements / activities / site_settings`، وحاوية `media`.
- `js/timetable-view.js` — عرض وطباعة استعمال الزمن (مشترك بين الموقع العام ولوحة الإدارة).
- `js/admin-tt.js` — محرر استعمال الزمن. `js/admin-cms.js` — محرك عام لبقية الأقسام + رفع الملفات + معلومات المؤسسة.
- `js/admin.js` — يوفّر الآن سجلّ وحدات `ADM.views`/`ADM.sections` ونافذة/تأكيد مشتركين (`ADM.modal`, `ADM.confirmBox`) تستعملهما كل الوحدات.
- الموقع العام (`js/app.js`): استعمال الزمن يُعرض من أحدث الجداول **المنشورة** فقط (RLS)، ولا بيانات تجريبية إن كان Supabase مُعدًّا.

## نموذج البيانات (استعمال الزمن)
جدول واحد = سنة دراسية + مستوى + قسم + أيام الدراسة. فيه حصص (`timetable_periods`: رقم، تسمية اختيارية، وقت البداية/النهاية، استراحة أم لا) وموادّ لكل خانة (يوم × حصة) في `timetable_entries` (مادة، أستاذ اختياري، قاعة اختيارية). يسمح هذا بتعديل كل حصة على حدة، ونسخ جدول إلى قسم آخر، واستعمال نفس بنية الحصص لعرض/طباعة/تصدير PDF (عبر نافذة الطباعة).

## القواعد المفروضة في قاعدة البيانات (وليس الواجهة فقط)
- لا تداخل زمني بين حصتين في نفس الجدول (constraint trigger مؤجَّل).
- لا مادة داخل فترة استراحة، ولا حصة ليوم خارج أيام الجدول.
- نشر منشور واحد فقط لكل (سنة، مستوى، قسم) — فهرس فريد جزئي + دالة `publish_timetable` تؤرشف السابق وتتحقق من وجود حصص قبل النشر.
- `timetable_conflicts(id)`: تنبيه (لا يمنع) عند تكرار نفس الأستاذ أو القاعة في نفس الوقت بجدول آخر.
- الروابط (صور/ملفات/شبكات اجتماعية) https فقط، والبريد ورقم الهاتف يُتحقق من صيغتهما في `site_settings` عبر trigger.

## الرفع الآمن
يتحقق `admin-cms.js` من: النوع المعلن ضمن القائمة المسموحة، الحجم الأقصى (8MB صور / 10MB ملفات)، **وتوقيع الملف الفعلي (magic bytes)** لا امتداده فقط. الصور تُصغَّر إلى 1600px وتُحوَّل WebP في المتصفح قبل الرفع (يزيل أيضًا بيانات EXIF مثل الموقع الجغرافي). يحمل الطلب رمز المسؤول، والحماية الفعلية في سياسات Storage (RLS) وليس في الواجهة.

## ما لم يُبنَ بعد
تعديل جماعي (Bulk)، سجلّ تدقيق لمن غيّر ماذا، سلة محذوفات، صفحات PDF مصمَّمة خصيصًا (الاعتماد حاليًا على طباعة المتصفح)، وربط «الأستاذ(ة)» في استعمال الزمن بجدول `teachers` (حاليًا نص حر لمرونة الإدخال).
