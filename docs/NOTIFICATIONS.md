# مركز إشعارات الرازي (RAZI NOTIFICATIONS)

قناتان: (أ) **داخل الموقع** لكل زائر بلا حساب، (ب) **Web Push** اختياري لمن يوافق صراحة. لا يُدّعى أن الإشعارات الحية تعمل قبل تنفيذ الترحيل وإعداد VAPID والنشر والاختبار على الإنتاج.

## 1) الترحيل (يدويًا في Supabase → SQL Editor)
1. خذ نسخة احتياطية.
2. الصق محتوى `supabase/migrations/003_notifications.sql` كاملًا ونفّذه (آمن لإعادة التشغيل).
3. نفّذ `supabase/tests/rls_checks_notifications.sql` للتحقق (transaction ثم rollback): المتوقع 1 إشعار ظاهر للزائر، و1 إشعار لإعلان نُشر وعُدّل وأُعيد نشره، و0 عند `notify=false`.
4. يضيف الترحيل: جدولي `notifications` و`push_subscriptions` (RLS مفعّل)، دوال `register/remove_push_subscription` و`admin_*`، عمود `announcements.notify`، ومشغّلات تنشئ إشعارًا داخليًا **مرة واحدة** عند أول نشر لخبر/إعلان/استعمال زمن/مورد. لا يعدّل 001 ولا 002، ولا يُرسل Push تلقائيًا.
5. **لم يُنفَّذ هذا الترحيل على قاعدتك الحية من طرفي.**

## 2) متغيرات Vercel (Production وPreview)
| المتغير | ملاحظة |
|---|---|
| `VAPID_PUBLIC_KEY` | عام (يُقدَّم للمتصفح عبر `GET /api/push-subscription`) |
| `VAPID_PRIVATE_KEY` | **سرّي** — الخادم فقط |
| `VAPID_SUBJECT` | `mailto:you@domain` أو `https://…` |
| `SUPABASE_URL`, `SUPABASE_ANON_KEY` | موجودان (anon فقط؛ لا service-role في أي مكان) |

توليد المفاتيح مرة واحدة (على جهازك): `npx web-push generate-vapid-keys` ثم ضعهما في Vercel. بعدها `npm install` (يضيف `web-push` ويحدّث lockfile) ثم أعد النشر. تغيير المفتاح العام لاحقًا يُبطل كل الاشتراكات القائمة.

## 3) البنية
`المتصفح ↔ /api/push-subscription (GET مفتاح عام · POST subscribe/unsubscribe) → دوال SQL محكومة (بمفتاح anon)`
`لوحة الإدارة → /api/push-send {notificationId} + رمز المشرف → Supabase Auth /user → is_admin() → admin_claim_push (حجز ذرّي مرة واحدة) → web-push → حذف 404/410`
- لا service-role: صلاحيات الإرسال تأتي من رمز المشرف نفسه ودوال `admin_*` التي تتحقق من `is_admin()` داخل قاعدة البيانات.
- **عدم التكرار:** `admin_claim_push` يضبط `push_sent_at` ذريًّا؛ الطلب الثاني → 409. فشل كامل (0 وصول) يُرجع الحجز لتمكين إعادة محاولة صريحة. تعديل إشعار منشور لا يرسل شيئًا.
- **قيد معروف:** دالة التسجيل قابلة للاستدعاء بمفتاح anon مباشرة (بدون service-role لا يمكن حصرها بالخادم). الحماية: قيود CHECK، سقف 20000 اشتراك، لا قراءة لأي اشتراك، وفحص مضيفي خدمات Push (حماية SSRF) عند التسجيل والإرسال. الحدّ من الطلبات في ذاكرة النسخة (best-effort) — للحماية الأقوى استعمل Vercel Firewall.
- مقروء/غير مقروء للزائر: `localStorage["razi_nt_v1"] = {v:1, read:[ids…]}` (حتى 200 معرّف، يُهمل التالف). لا تُرسل أي بيانات شخصية. الإشعارات المنتهية/المسودات لا تظهر علنًا (لذا «السجل» يعرض المقروء ضمن الفعّالة فقط).

## 4) سير عمل المشرف
- **تلقائي (داخل الموقع):** نشر خبر/إعلان/استعمال زمن/مورد ⇒ إشعار واحد. للإعلان خانة «إنشاء إشعار» (افتراضيًا مفعّلة؛ تعمل بعد الترحيل).
- **يدوي:** لوحة الإدارة ← «إدارة الإشعارات»: إنشاء/تعديل/معاينة عربي-فرنسي/جدولة/انتهاء/نشر/أرشفة/حذف، ومعرفة عدد اشتراكات Push.
- **Push:** فقط بالضغط على «إرسال Push» أو بتحديد خانة الإرسال عند الحفظ، مع تأكيد، والإشعار «منشور» ووقته الآن.

## 5) الاختبار
- محليًا: `npm run test:push` و`npm run test:ui` (محاكاة؛ لا حصة ولا شبكة). Push الحقيقي يتطلب HTTPS: استعمل نشر Preview أو `localhost` (Chrome يعامله كآمن)، افتح الجرس ← «تفعيل إشعارات الرازي» ← وافق، ثم أرسل من لوحة الإدارة.
- الإنتاج: جرّب بجهازك أولًا قبل الإعلان للزوار.

## 6) توافق المتصفحات
Chrome/Edge/Firefox (حاسوب وأندرويد): مدعوم. Safari macOS 13+: مدعوم. **iPhone/iPad:** iOS 16.4+ **وبعد إضافة الموقع إلى الشاشة الرئيسية فقط** (يوجد `manifest.webmanifest`). متصفحات داخل التطبيقات (WebView) غالبًا غير مدعومة. الإشعارات داخل الموقع تعمل في كل الأحوال حتى مع رفض الإذن.

## 7) التراجع
`supabase/rollbacks/003_rollback.sql` (يحذف الجدولين والدوال والمشغّلات؛ احتفظ بنسخة قبله). لإيقاف Push فقط: احذف `VAPID_*` من Vercel (يبقى مركز الإشعارات الداخلي). لإيقاف الواجهة: أزل وسمي `<script>` الخاصين بـ `js/notifications.js` و`js/reveal.js`.

## 8) كشف المحتوى عند التمرير
`js/reveal.js` (يستبدل مسار `.rv` القديم في `app.js` الذي صار احتياطًا فقط). يُخفى المحتوى فقط بعد نجاح التهيئة (`html.js-reveal`)؛ مرة واحدة؛ `opacity`+`translate`/`scale`؛ يحترم `prefers-reduced-motion`؛ مبسّط عند توفير البيانات/الأجهزة الضعيفة؛ لا يمس الـ Hero. واجهة يدوية: `data-reveal="up|left|right|scale|img"` و`data-reveal-delay="ms"` أو `.reveal-up` إلخ. عدّاد الأرقام (`data-to`) باقٍ كما كان.
